# OOP-With-JAVA

This repository provides comprehensive examples and resources to learn **Object-Oriented Programming (OOP)** concepts using Java. It is designed to help learners build a solid foundation in OOP principles while exploring practical implementations.

## 📁 Project Structure

The repository is organized into multiple files and directories covering various OOP topics, including advanced concepts:

### Key Java Files and Topics
- **AbstractionClass.java**: Explains abstraction using abstract classes.
- **AbstractionMethod.java**: Demonstrates abstraction through abstract methods.
- **Con_copy.java**: Shows the implementation of copy constructors.
- **Con_overloading.java**: Covers constructor overloading in Java.
- **Con_parameterized.java**: Explains parameterized constructors.
- **HierarchicalInheritance.java**: Demonstrates hierarchical inheritance.
- **InstanceBlock.java**: Covers the use of instance initialization blocks.
- **Interface.java**: Demonstrates the implementation of interfaces in Java.
- **Loop.java**: Examples of various looping constructs in Java.
- **MultilevelInheritance.java**: Illustrates multilevel inheritance.
- **Polymoverloading.java**: Explains method overloading as an example of polymorphism.
- **polyoverrideannotation.java**: Demonstrates method overriding with annotations.
- **Quiz1.java**: A quiz file to test your Java and OOP knowledge.
- **Sensor.java**: A practical example demonstrating encapsulation.
- **SimpleInheritance.java**: Explains basic inheritance concepts.
- **StaticBlock.java**: Demonstrates the use of static initialization blocks.
- **StaticVSInstanceBlock.java**: Compares static and instance initialization blocks.
- **SuperKeyword.java**: Covers the use of the `super` keyword in inheritance.
- **Test.java**: A sample file for testing various Java concepts.
- **ThisKeyword.java**: Explains the use of the `this` keyword for current instance references.

### 1. **Coupling & Cohesion**
   - Demonstrates low coupling and high cohesion for modular and maintainable code.

### 2. **Enum**
   - Explores the use of Enums in Java to define a set of constants with additional behavior.

## 🏷️ OOP Concepts Covered

This repository covers **all major OOP concepts**:

1. **Abstraction**: Hiding implementation details to show only the essentials.
2. **Encapsulation**: Protecting data by bundling it with methods to control access.
3. **Inheritance**: Allowing a class to inherit properties and behaviors from another.
4. **Polymorphism**: Enabling a single interface to represent different implementations (method overloading and overriding).
5. **Constructors**: Working with default, parameterized, copy constructors, and constructor overloading.
6. **Instance and Static Blocks**: Using initialization blocks for specific scenarios.
7. **Interfaces**: Understanding multiple inheritance through interfaces.
8. **Super and This Keywords**: Learning to manage current and parent class references.

## 🚀 How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/AfrinJahanEra/OOP-With-JAVA.git
   ```
2. Navigate to the desired folder or file to explore the examples.
3. Compile and run the `.java` files using a Java compiler or IDE:
   ```bash
   javac FileName.java
   java FileName
   ```
